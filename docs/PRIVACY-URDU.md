# FarooqDrive — رازداری

تازہ کاری: 6 ستمبر 2026۔ ناشر: محمد فاروق۔ رابطہ: support@mymandoob.com۔ یہ تفصیل Windows 21.1 کے Google Drive اور Microsoft OneDrive افعال کی ہے؛ ویب اور موبائل میں دستیابی مختلف ہو سکتی ہے۔

آپ کی اجازت سے نام، ای میل، اجازت کے tokens، گنجائش اور فائلوں کے نام، IDs، سائز، راستے اور تاریخیں استعمال ہوتی ہیں تاکہ اکاؤنٹس، فہرست، تلاش، duplicate تجاویز اور آپ کی مطلوبہ کارروائیاں ممکن ہوں۔ اصل مواد مطلوبہ upload، download، copy، export یا منتقلی کی تصدیق کے لیے پڑھا جاتا ہے۔ duplicate scan صرف metadata پڑھتا ہے۔

فائلیں براہ راست آپ کے آلے اور منتخب Google/Microsoft سروس کے درمیان جاتی ہیں۔ FarooqDrive درمیانی فائل ذخیرہ یا analytics سرور نہیں چلاتا، اکاؤنٹ/فائل ڈیٹا فروخت نہیں کرتا اور اشتہارات کے لیے استعمال نہیں کرتا۔ Google APIs سے حاصل معلومات کا استعمال اور منتقلی Google API Services User Data Policy اور Limited Use شرائط کے مطابق ہوگی۔ متعلقہ سروس کی اپنی پالیسی اور ادارے کی اجازت بھی لاگو ہے۔

## آلے پر محفوظ معلومات

اجازت کی اسناد Windows کے secure-storage نظام میں محفوظ ہوتی ہیں۔ پاس ورڈ متعلقہ سروس کے براؤزر صفحے پر درج ہوتا ہے۔ ظاہری انداز، ترتیب اور configuration مقامی طور پر محفوظ رہتے ہیں۔

Scan index میں فائل metadata، اکاؤنٹ شناخت/ای میل، راستے، نتائج، مقدار اور وقت محفوظ ہوتا ہے؛ اصل مواد یا tokens نہیں۔ app اسے encrypt نہیں کرتی۔ یہ کامیاب Rescan تک برقرار رہتا ہے؛ عام Refresh اسے نہیں بدلتا۔ Disconnect سے اس اکاؤنٹ کا محفوظ index ہٹتا ہے۔ نتائج وقت کے ساتھ پرانے ہو سکتے ہیں۔

مقامی History میں زیادہ سے زیادہ 400 اندراج ہو سکتے ہیں، جن میں فائل نام، راستے، کارروائی، ای میل اور وقت شامل ہیں۔ سات دن سے پرانے اندراج لوڈ یا محفوظ کرتے وقت چھانٹے جاتے ہیں؛ app بند ہونے پر یہ مسلسل چلنے والا خودکار حذف نہیں۔ Clear History محفوظ تاریخ صاف کرتا ہے۔

Windows کی تشخیصی فائل `%LOCALAPPDATA%\FarooqDrive\farooqdrive-crash.log` الگ ہے اور اس پر سات دن کی خودکار حد نہیں۔ یہ خود ناشر کو نہیں بھیجی جاتی۔ support کو بھیجنے سے پہلے اسے دیکھیں؛ passwords یا tokens نہ بھیجیں۔

## عارضی مواد اور منتقلی

Windows Temp کے `FarooqDrive-transfers` job folders میں منتقلی یا Upload کا عارضی اصل مواد آ سکتا ہے۔ app اسے encrypt نہیں کرتی۔ مناسب خالی جگہ رکھیں۔ معمول کے اختتام/ناکامی پر job کی فائل ہٹتی ہے، crash پر رہ سکتی ہے؛ app بند کرکے باقی folders دستی طور پر صاف کریں۔ Uninstall سے تمام cache، اسناد یا log حذف ہونے کا فرض نہ کریں۔

منزل دوبارہ download کرکے SHA-256 جانچ اضافی انٹرنیٹ استعمال کرتی ہے۔ رکاوٹ کے بعد منزل پر نقول رہ سکتی ہیں؛ دوبارہ چلانے سے خودکار resume نہیں ہوتا۔ Move میں اہل، غیر تبدیل شدہ OneDrive اصل فائل کی Recycle Bin صفائی کے لیے آخری Yes/No الگ ہے۔ No پر اصل رہتا ہے۔ Google کی اصل فائلیں اور اصل فولڈر محفوظ مشروط صفائی نہ ہونے پر برقرار رہتے ہیں۔ عام Trash الگ مطلوبہ کارروائی ہے۔

## اختیار، حذف اور رابطہ

آپ اکاؤنٹ اور کارروائی منتخب کرتے ہیں۔ Disconnect سے app کی اسناد/index ہٹتے ہیں، cloud فائلیں نہیں؛ متعلقہ provider کی connected-app settings سے اجازت الگ واپس لے سکتے ہیں۔ ادارے کا منتظم اجازت کنٹرول کر سکتا ہے۔ History، تشخیصی log اور باقی عارضی مواد الگ صاف کریں۔ تنصیب ختم کرتے وقت اکاؤنٹس disconnect کرکے مقامی app data بھی ہٹایا جا سکتا ہے۔

ویب میں browser/session کی OAuth اور دستیاب browser storage استعمال ہوتی ہے؛ یہ اپ ڈیٹ ویب/موبائل میں OneDrive فعال نہیں کرتی۔ آپ support کو خود جو معلومات بھیجیں، وہ درخواست کے جواب اور تشخیص کے لیے استعمال ہوتی ہیں۔ پالیسی میں تبدیلی کی تاریخ ظاہر کی جائے گی۔ سوال یا ناشر کو براہ راست بھیجی گئی معلومات کی درخواست کے لیے support@mymandoob.com سے رابطہ کریں۔
