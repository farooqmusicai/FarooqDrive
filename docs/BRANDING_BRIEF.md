# FarooqDrive Branding

## Official approved icon
The official FarooqDrive icon is the database-and-folders artwork supplied and approved by the project owner on 2026-09-02.

Use this same identity consistently for:
- Windows executable and application window
- FarooqDrive Setup installer and shortcuts
- Microsoft Store/MSIX assets
- Google OAuth application branding
- GitHub repository/release branding
- Documentation and public release materials

## Source and exports
- `assets/branding/FarooqDrive-icon-master.png` — approved master PNG
- `assets/branding/FarooqDrive-icon-512.png` — general high-resolution use
- `assets/branding/FarooqDrive-icon-128.png` — GitHub/README use
- `build/FarooqDrive.ico` — multi-resolution Windows icon
- `build/FarooqDrive.png` — packaged Electron window icon
- `store/Assets/` — Microsoft Store/MSIX derivatives

Do not replace this icon with Electron/default placeholder artwork in release builds.
