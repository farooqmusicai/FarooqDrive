# FarooqDrive Public Release Checklist

## Required before the first public binary
- [ ] Final FarooqDrive logo/icon approved and exported in Windows/Store sizes.
- [ ] Production Google Cloud project created.
- [ ] Google Drive API enabled.
- [ ] Desktop OAuth client created.
- [ ] Public privacy-policy URL online.
- [ ] Public support email/page online.
- [ ] OAuth production/brand verification completed if required by Google for the final configuration.
- [ ] Microsoft Partner Center developer account ready.
- [ ] `FarooqDrive` name reserved in Microsoft Store if available.
- [ ] Store identity values inserted into the final package manifest/configuration.
- [ ] Windows 11 clean-machine installer test passed.
- [ ] Windows 10 test passed if Windows 10 will be advertised.
- [ ] Google login/connect with at least two accounts tested.
- [ ] Upload selection tested when one account has insufficient space.
- [ ] Large resumable upload tested.
- [ ] Manual sync tested.
- [ ] Preview/download/rename/move/trash tested.
- [ ] Account disconnect/reconnect tested.
- [ ] Uninstall behavior tested; Google Drive files remain untouched.
- [ ] Dependency licenses reviewed and third-party notices updated.
- [ ] Direct-download EXE code-signed if distributed outside Store.
- [ ] Store screenshots and listing copy finalized.
