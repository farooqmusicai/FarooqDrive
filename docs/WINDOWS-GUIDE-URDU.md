# FarooqDrive برائے ونڈوز

## عام صارف کے لیے

1. `FarooqDrive-Setup-v19.0.0-Windows-x64.exe` چلائیں۔
2. تنصیب مکمل ہونے کے بعد FarooqDrive کھولیں۔
3. **گوگل اکاؤنٹ شامل کریں** کا بٹن دبائیں اور براؤزر میں اجازت منظور کریں۔
4. مزید اکاؤنٹس شامل کرنے کے لیے یہی عمل دہرائیں۔
5. بائیں جانب کوئی اکاؤنٹ یا **تمام ڈرائیوز** منتخب کرکے فائلیں استعمال کریں۔

انسٹالر موجودہ ونڈوز صارف کے لیے پروگرام نصب کرتا ہے، اسٹارٹ مینیو میں شارٹ کٹ
بناتا ہے، اختیاری ڈیسک ٹاپ شارٹ کٹ فراہم کرتا ہے اور ونڈوز سیٹنگز کے ذریعے مکمل
طور پر حذف کیا جا سکتا ہے۔

## پروگرام تیار کرنے والے کے لیے

ضروریات: 64 بٹ ونڈوز 10 یا 11، Flutter کا مستحکم نسخہ، Visual Studio میں
Desktop development with C++، Inno Setup 6 اور Git۔

```powershell
cd apps/flutter
flutter pub get
flutter build windows --release
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" installer/FarooqDrive.iss
```

انسٹالر `apps/flutter/release` میں بنے گا۔ قابل نقل فائلیں
`apps/flutter/build/windows/x64/runner/Release` میں ملیں گی۔

حتمی اجرا سے پہلے صاف ونڈوز 10 اور 11 کمپیوٹر، محدود صارف اکاؤنٹ، تنصیب و حذف،
گوگل اجازت، متعدد اکاؤنٹس، بڑی فائل اپ لوڈ، پیش منظر، ڈاؤن لوڈ اور ٹوکن کی تجدید
کی جانچ کریں۔

دستخط کے بغیر آزمائشی انسٹالر پر Windows SmartScreen تنبیہ دکھا سکتا ہے۔ حتمی
اجرا میں دستخطی سرٹیفکیٹ صرف GitHub Secrets کے ذریعے استعمال ہوگا۔ سرٹیفکیٹ یا
اس کا پاس ورڈ repository میں شامل نہیں کیا جائے گا۔
