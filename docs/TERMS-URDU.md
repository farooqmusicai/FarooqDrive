# FarooqDrive — استعمال کی شرائط

تازہ کاری: 6 ستمبر 2026۔ ناشر: محمد فاروق۔ رابطہ: support@mymandoob.com۔

FarooqDrive ایک آزاد فائل مینیجر ہے۔ اسے صرف مجاز اکاؤنٹس/فائلوں، قابل اطلاق قانون اور provider کی شرائط کے مطابق استعمال کریں۔ یہ Windows 21.1 کی Google Drive/OneDrive خصوصیات کی تفصیل ہے؛ ویب/موبائل مختلف ہو سکتے ہیں۔

آپ اکاؤنٹس، منزل اور کارروائی منتخب کرتے ہیں۔ app اضافی cloud storage فروخت نہیں کرتی، اکاؤنٹس کی گنجائش کو نئی حقیقی ڈرائیو نہیں بناتی، اور متعدد اکاؤنٹس میں ایک فائل تقسیم ہونے کی ضمانت نہیں۔ quota، اجازت، دستیابی، Recycle Bin اور ادارے کی پابندیاں متعلقہ سروس کے اختیار میں ہیں۔ app کی اکاؤنٹ تعداد کی مقررہ حد نہ ہونا لامحدود کارکردگی کی ضمانت نہیں۔

Cut اکیلا اصل حذف نہیں کرتا۔ اہل Move پہلے نقل اور مواد کی جانچ کرکے الگ آخری Yes/No پوچھتا ہے۔ صرف اہل، غیر تبدیل شدہ OneDrive اصل فائلیں مشروط طور پر Recycle Bin میں جا سکتی ہیں۔ Google کی اصل فائلیں اور اصل فولڈر جہاں یہ محفوظ شرط دستیاب نہیں، برقرار رہتے ہیں۔ No پر دونوں نقول رہتی ہیں۔ Google-native دستاویز کی اسی اکاؤنٹ میں نقل اپنی قسم برقرار رکھتی ہے؛ دوسرے اکاؤنٹ کی معاون export میں شکل بدل سکتی ہے اور ہر metadata/خصوصیت محفوظ رہنے کی ضمانت نہیں۔ عام Trash الگ مطلوبہ کارروائی ہے۔

فی فائل منتقلی 1 GiB، فی کام 10,000 اشیاء اور 64 فولڈر سطحوں تک ہے۔ OneDrive Download-to-PC کی حد 32 MiB ہے۔ یہ app کی حدود ہیں، provider کی زیادہ سے زیادہ گنجائش نہیں۔ مناسب خالی ڈسک رکھیں؛ عارضی مواد app encrypt نہیں کرتی۔ تصدیق کے لیے دوبارہ download انٹرنیٹ استعمال کرتا ہے۔ crash کے بعد باقی عارضی folders app بند کرکے صاف کریں۔ منزل پر نقول رہ سکتی ہیں اور retry سے مزید نقل بن سکتی ہے۔ دوبارہ شروع کرنے پر خودکار resume نہیں۔

محفوظ scan نتائج کامیاب Rescan تک برقرار رہتے ہیں اور پرانے ہو سکتے ہیں۔ عام Refresh موجودہ فہرست تازہ کرتا ہے۔ یکساں نام/سائز مکمل مواد کی یکسانیت ثابت نہیں کرتے۔ scan خود کچھ حذف نہیں کرتا۔ اہم کارروائی سے پہلے جائزہ لیں اور backup رکھیں۔ Explorer-style منظر cloud drive کو Windows Explorer میں mount نہیں کرتا؛ native desktop drag-in/drag-out یا مسلسل folder sync شامل نہیں۔

Privacy میں اسناد، index، تاریخ، diagnostics اور عارضی مواد کی تفصیل ہے۔ اپنی Windows شناخت اور credentials محفوظ رکھیں۔ repository کے software licenses اور تیسرے فریق کے notices الگ ہیں اور لاگو رہتے ہیں۔ عوامی code میں ذاتی secrets یا signing keys شامل نہ ہوں۔
