# User help

- **All Drives** combines items from connected accounts.
- Select an account to browse its folders from My Drive.
- Double-click a folder to enter it; use the breadcrumb to go back.
- Use checkboxes for multi-select. Toolbar actions apply to selected items.
- **Copy/Cut**, open a destination folder, then **Paste**.
- Upload chooses the current account; in All Drives it chooses the account with
  the most reported free storage.
- Deleting moves items to Google Drive Trash.
- Disconnect removes the account from the current app/session; it does not delete
  Google files.
