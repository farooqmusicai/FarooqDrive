# FarooqDrive user help

Urdu version: [USER-HELP-URDU.md](USER-HELP-URDU.md)

The same workflow applies to the Web and Windows editions.

## Connect Google accounts

1. Select **Add Google account**.
2. Sign in through the Google page opened by FarooqDrive.
3. Review and approve the requested Google Drive access.
4. Repeat for every Drive you want to connect.

Disconnecting an account removes it from FarooqDrive on the current device or
browser session. It does not delete files from Google Drive.

## Browse and find items

- **All Drives** combines indexed items from every connected account.
- Select an account in the sidebar to browse its **My Drive**.
- Double-click a folder to enter it. Use **Back**, **Up**, or any breadcrumb path
  segment to navigate.
- **All** displays folders and files together and remains selected until the user
  chooses another view.
- **Folders** and **Files** show only that item type.
- Search matches names, file types, paths, and account information across indexed
  Drives. Tab totals represent the matching results currently displayed.
- Hover over shortened names, accounts, paths, sizes, and dates for the complete
  value. Desktop column widths can be adjusted by dragging their dividers.

## Manage files

- Use checkboxes for multi-select. Toolbar actions apply to selected items.
- To move precisely: choose **Cut**, open the destination Drive/folder, then
  choose **Paste**.
- **Copy** keeps the original and creates a copy at the selected destination.
- Upload uses the selected account. In **All Drives**, FarooqDrive selects an
  account with sufficient reported free storage.
- Download saves a local copy; Google-native files open through their Google link.
- Trash moves items to Google Drive Trash, where Google retention rules apply.

## Storage, progress, and history

- Capacity and usage values come from the Google Drive API. Folder/indexed file
  size and Google quota usage can differ because Google-native files, shared data,
  trash, revisions, and other Google storage may be treated differently.
- A progress overlay appears while long operations or indexing are running.
- The history icon shows locally recorded activity from the last 7 days. Users can
  clear it at any time.
