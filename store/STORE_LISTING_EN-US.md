# Microsoft Store Listing - English (United States)

## Product name
FarooqDrive

## Short description
Connect multiple Google Drive accounts and manage their FarooqDrive files from one Windows dashboard.

## Full description
FarooqDrive brings multiple Google Drive accounts into one clean Windows desktop dashboard. Connect accounts you control, view combined storage information, and let FarooqDrive select an authorized Drive with enough available space when you upload a file.

FarooqDrive keeps file bytes in Google Drive. Each connected account uses a folder named `Farooqdrive`, while virtual folders in the desktop app let you organize files across different connected accounts in one view.

Key capabilities include combined storage totals, per-account quota information, resumable uploads with progress, virtual folders, file preview and download, rename, virtual move, Google Drive trash, account disconnect, and manual metadata sync.

Google authorization opens in your normal browser. FarooqDrive does not ask for your Google password and uses the narrower `drive.file` permission for files the app creates or that you authorize for the app.

## Features
- Connect multiple Google Drive accounts
- Combined total, used and free storage dashboard
- Automatic upload-account selection based on available quota
- Direct Google Drive resumable uploads with progress
- Virtual folders across multiple connected accounts
- Manual sync from Farooqdrive folders
- Preview, download, rename, move and trash files
- Local encrypted OAuth token storage
- Embedded local database; no separate MySQL or Docker installation
