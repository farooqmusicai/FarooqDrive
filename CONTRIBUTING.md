# Contributing to FarooqDrive

Thank you for contributing. Please open an issue before a major architectural change. Keep changes focused, do not commit secrets or user data, and test login, Google account connection, quota refresh, upload, sync, preview/download, rename, move and delete behavior when those areas are affected.

Pull requests should include a concise description, testing notes, screenshots for visible UI changes, and any privacy/security impact. By contributing, you agree that your contribution may be distributed under the repository's MIT License.
